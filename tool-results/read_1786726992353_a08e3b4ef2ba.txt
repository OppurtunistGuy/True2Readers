    25→
    26→Home:
    27→- TrueRead branding (book + sparkles icon; "True" navy + "Read" blue)
    28→- One prominent search box (accepts a specific title OR a genre/topic)

    33→- Specific title match → skip straight to Book Detail (single best match)

    38→- Responsive grid, no filters. Simple sort (Relevance/Newest/Oldest on the page).

    41→
    42→Book Detail:
    43→- Cover, title, author, meta (year, publisher, pages, categories)

    45→- Static/mock AI-style breakdown (Pacing, Tone, Dialogue Density) — deterministic from book id, no real AI call.
    46→- "Source: Google Books" attribution.
    47→
    48→Explicitly NOT built: login/signup, accounts, database, favorites, reviews, ratings UI, buy/affiliate links, real AI call, recommendation engine, extra filters, complex nav, extra page routes.

    50→## API contract (shared — both backend & frontend must conform)
    51→
    52→```ts
    53→// src/components/trueread/types.ts
    54→export interface Book {
    55→  id: string
    56→  title: string
    57→  authors: string[]
    58→  year: string | null            // 4-digit year from publishedDate
    59→  cover?: string                 // https image URL
    60→  description?: string
    61→  previewSnippet?: string        // searchInfo.textSnippet (may contain <em>...</em>)
    62→  previewLink?: string
    63→  categories?: string[]
    64→  publisher?: string
    65→  pageCount?: number | null
    66→  rating?: number | null
    67→  embeddable?: boolean
    68→  viewability?: string
    69→}
    70→
    71→export interface SearchResponse {
    72→  query: string
    73→  mode: 'title' | 'genre'
    74→  bestMatch: Book | null
    75→  results: Book[]
    76→  totalItems: number
    77→  startIndex: number
    78→  maxResults: number
    79→}
    80→```
    81→
    82→Endpoint: `GET /api/books/search?q=<query>&startIndex=<0>&maxResults=<24>` → `SearchResponse`
    83→- On startIndex 0: backend decides mode via title-match heuristic (token Jaccard ≥ 0.6 or substring between query and top result's title). Title match → mode 'title', bestMatch = top result. Else mode 'genre', bestMatch null.
    84→- On startIndex > 0: always mode 'genre' (pagination), bestMatch null.

   119→- Created src/lib/google-books.ts (server-only module):
   120→  - mapVolume(volume): defensively extracts Book fields with safe fallbacks (title → 'Untitled', authors → [], year via /^(\d{4})/ on publishedDate, cover from imageLinks preferring extraLarge→large→medium→thumbnail→smallThumbnail with http→https rewrite, previewSnippet kept raw including <em> tags, pageCount/rating coerced to number|null, embeddable/viewability from accessInfo).
   121→  - isTitleMatch(query, title): normalize (lowercase, strip non-alphanumeric keeping spaces, trim, collapse ws); exact match → true; substring in either direction only if shorter side length >= 3; else token-Jaccard >= 0.6.
   122→  - In-memory cache: module-level Map<string,{ts,data}>, key = `${query}::${startIndex}::${maxResults}`, TTL 600_000ms, getCached (deletes stale) + setCached.
   123→  - searchBooks(query, startIndex=0, maxResults=24): clamps maxResults to 1..40, builds https://www.googleapis.com/books/v1/volumes URL with q/startIndex/maxResults/printType=books (NO langRestrict), appends &key=GOOGLE_BOOKS_API_KEY if set, fetch with { next: { revalidate: 600 } }, returns {results, totalItems} (empty on 0 totalItems / no items), filters out items with no id, caches success, throws Error on fetch/HTTP-non-ok/JSON-parse failure.
   124→  - decideMode(query, results): 0 results → {genre, null}; 1 result → {title, results[0]}; >1 → title iff isTitleMatch(query, results[0].title) else {genre, null}.
   125→- Created src/app/api/books/search/route.ts (Next.js 16 Route Handler, GET):
   126→  - Parses q (required, trimmed), startIndex (default 0, clamp >=0), maxResults (default 24, clamp 1..40).
   127→  - 400 on missing/empty q.
   128→  - Calls searchBooks; on startIndex===0 calls decideMode to set {mode, bestMatch}; on startIndex>0 forces {genre, null}.
   129→  - Builds SearchResponse body, returns Response.json with Cache-Control: no-store.
   130→  - try/catch → 502 {error:'Failed to fetch books', detail:String(err.message)} with console.error log.
   131→  - Exports dynamic='force-dynamic'.
